# 成员3第一阶段模拟器、分析服务与Web联动任务

## 目标

让模拟器通过成员1的TCP协议写入遥测，让FastAPI和浅色Web大屏从同一模拟数据库读取运营数据，实现车主端、运营端和Web大屏联动。

## 2026-09-08 集成状态更新

成员3与成员1的核心数据链路已经完成：模拟器使用正式长度头TCP协议发送`PILE_TELEMETRY`，成员1服务端将遥测和告警写入唯一SQLite模拟库，FastAPI通过`CHARGE_PLATFORM_DB`只读该库，Web大屏通过`/dashboard`每3秒刷新。Ubuntu联调已实际观察到遥测记录`0→6`、告警`3→4`；最新Windows本地检查返回`state=normal`和`sourceStatus=connected`。

当前剩余项不是重新改造成员3模块，而是等待成员2把Qt车主端和运营端从`MockDataProvider`切换到成员1正式接口，再执行“Qt操作改变数据库—运营端刷新—大屏3秒内同步”的两遍整组人工验收。

## 模型说明

第一阶段大屏的重点是数据库联动。现有模型训练和评估可以保留，但如果数据评测选择`BASELINE`，页面和答辩必须如实显示基线回退，不能称为在线机器学习预测已经完成。

## 禁止事项
