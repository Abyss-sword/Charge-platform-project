# 第一阶段三端联动基线

> **状态：已冻结，适用于9月10日第一阶段验收。**

## 1. 调整结论

第一阶段不再以“窗口存在、能够切换、固定Mock数据显示正常”为完成标准。车主端、运营端、充电桩模拟器、分析服务和Web大屏必须围绕成员1维护的SQLite模拟数据库形成可操作闭环。

这里的“模拟”只表示账号、站点、电桩、支付和遥测数据是教学模拟数据，不表示按钮可以只做页面跳转。登录、查询、预约、充电、停止、充值、支付、告警和工单操作必须经过服务端业务逻辑，并真实改变模拟数据库状态。

第二阶段不再补第一阶段遗漏的窗口、登录、支付或三端通信。第二阶段主要将模拟数据替换为合法的匿名数据或公开聚合数据，并完成字段映射、清洗、质量、预测、推荐、回算和性能验证。

## 5. 统一完成定义

一项功能只有同时满足下列条件才能标记为完成：

1. 操作入口存在且可用；
2. 请求经过正式接口，不是本地修改文本；
3. 服务端执行规则并写入唯一模拟数据库；
4.重新查询可以看到结果；
5. 相关的其他端能够在刷新后看到同一结果；
6. 成功、失败和断线状态有明确反馈；
7. 自动测试或完整人工步骤可以复现；
8. 提交号和验证结果已记录。
