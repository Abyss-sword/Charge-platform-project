# 服务端线程与连接模型

主线程只负责监听端口和接收新连接。每个客户端连接由独立工作线程处理，该线程独占套接字、帧缓存和 SQLite 连接。请求路由只接收完整 JSON 并返回响应 JSON，不直接读取或写入套接字，因此协议解析、业务路由和传输可以分别测试。

处理顺序固定为：收字节 → 帧解码 → JSON/动作校验 → 路由 → 数据库短事务 → 生成响应 → 帧编码。协议错误只影响当前连接；未知动作返回 `PARAM_INVALID` 后连接仍可继续处理下一请求。线程结束时关闭并移除自己的数据库连接。

SQLite 的业务事实只有一份。客户端、Web 大屏和分析服务不得自行维护第二套订单或电桩状态；断线恢复后必须重新向服务端查询。
